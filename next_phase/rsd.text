1.Literature Review (Prothom Agent): Ekjon agent ke diye pura literature review korate hobe. Ei vishoye ki ki kaj ache ebong kon kon competitors ache ta dekhte hobe. Paper gulote kon kon paper mention kora hoyeche tar list ebong overview toiri korte hobe.  
2.Critical Review (Ditiyo Agent): Arekta agent ke diye kora mathematical derivation gulo ekjon critic ba reviewer hisebe judge korate hobe. Derivation e kono problem ba flaws ache kina ebong assumption gulo aje-baje neya hoyeche kina ta check korte hobe. Ei problem gulo kivabe fix kora jay tao dekhte hobe.  
3.RL System Data Khoja (Tritiyo Agent): Kono real-life RL (Reinforcement Learning) system er data ache kina ta khuje ber korte hobe. Ei data te model apply kore dekhate hobe je kajti actually collapse thamay ebong better result dey.
